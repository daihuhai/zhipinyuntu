## 一、用户免费额度用完后的充值引导

3. **首页配额状态卡片** - 在 Dashboard 首页顶部展示配额使用进度条，点击直接跳转 VIP 中心

## 三、注册后自动填账号 & 密码安全

### 现状
- 注册成功后仅 `router.push('/login')`，跳到空白登录页，用户需手动输入用户名
- 登录页密码框使用 `show-password` 属性，可切换明文显示密码
- 密码在 Network 面板中以明文传输（HTTPS 加密后实际不可见，但 DevTools 可查看请求体）
- 用户信息存储在 `localStorage` 中，浏览器控制台可直接读取

### 修正方案
1. **注册后自动填充用户名** - 注册成功后通过 `router.push({ path: '/login', query: { username: form.username } })` 传递，登录页自动读取并填入
2. **密码可见性开关默认关闭** - 保留 `show-password` 但默认为密码隐藏状态 (已实现)
3. **localStorage 敏感信息最小化** - `user_info` 中不存储 phone/email 等敏感信息，仅存储 id/username/nickname/role/avatar
4. **登录页增加"记住我"功能** - 当前 `remember` checkbox 无实际效果，可实现为 7 天免登录 (通过 refresh token)

### 涉及文件
| 文件 | 改动 |
|------|------|
| `frontend/src/views/auth/Register.vue` | 注册成功后传递 username 参数 |
| `frontend/src/views/auth/Login.vue` | 读取 query 参数自动填充用户名 |
| `frontend/src/stores/user.ts` | user_info 去除 phone/email 敏感字段 |
| `backend/app/api/v1/auth.py` | `/auth/me` 返回 phone/email 时脱敏 (138****1234) |

## 四、用户身份证等信息补全

### 现状
- SysUser 模型缺少 `id_card` (身份证号) 字段
- 求职者 Profile.vue 和注册页都没有身份证输入
- 个人用户仅有 real_name / gender / phone / email 字段

### 修正方案
1. **SysUser 新增字段**:
   - `id_card` VARCHAR(18) - 身份证号
   - `birth_date` DATE - 出生日期 (由身份证号自动解析)
   - `education` VARCHAR(32) - 最高学历
   - `work_years` SMALLINT - 工作年限
2. **注册页增加字段** - 个人用户注册时增加身份证号、学历、工作年限
3. **Profile 页增加编辑** - 求职者 Profile 页展示和编辑以上字段
4. **后台用户管理展示** - 管理员 Users.vue 表格显示身份证号(脱敏)

### 涉及文件
| 文件 | 改动 |
|------|------|
| `backend/app/models/user.py` | 新增 id_card/birth_date/education/work_years 字段 |
| `backend/app/schemas/auth.py` | RegisterRequest 新增字段 |
| `backend/app/api/v1/auth.py` | /auth/me 和 /auth/profile 返回/接收新字段 |
| `frontend/src/views/auth/Register.vue` | 个人用户表单新增字段 |
| `frontend/src/views/seeker/Profile.vue` | 展示和编辑新字段 |
| `frontend/src/views/admin/Users.vue` | 表格显示身份证号(脱敏) |

## 五、注册页提示词重叠

### 现状
- 注册表单使用 `label-position="top"` 但大部分字段没有 `label`，靠 `placeholder` 提示
- 密码框 placeholder 过长："密码 (至少8位, 含字母+数字)"
- 密码强度条位于密码框下方，与确认密码框间距较小
- 在较小屏幕上，表单内容可能溢出

### 修正方案
1. **为关键字段添加 label** - username/phone/email/password/confirmPassword 添加简短 label，placeholder 改为简短提示
2. **密码框 placeholder 缩短** - 改为"请输入密码"，强度规则放到 label 下方 hint
3. **间距优化** - 密码强度条与确认密码框间距增加到 12px
4. **表单滚动优化** - 右侧表单区 `max-height: 100vh; overflow-y: auto` 已实现，确认滚动条正常

### 涉及文件
| 文件 | 改动 |
|------|------|
| `frontend/src/views/auth/Register.vue` | 添加 label、缩短 placeholder、调整间距 |

## 七、用户反馈功能

### 现状
- 完全缺失，用户无法向系统管理员提交反馈或意见
- 没有 Feedback 模型、API 或前端页面

### 修正方案
1. **新建 Feedback 模型**:
   - id, user_id, type (bug/feature/other), title, content, status (pending/processing/resolved), admin_reply, created_at, updated_at
2. **后端 API**:
   - `POST /api/v1/feedback` - 用户提交反馈
   - `GET /api/v1/feedback/my` - 用户查看自己的反馈列表
   - `GET /api/v1/admin/feedbacks` - 管理员查看所有反馈
   - `PUT /api/v1/admin/feedbacks/{id}` - 管理员回复/更新状态
3. **前端页面**:
   - 求职者/企业 "个人设置" 页面增加"意见反馈" Tab
   - 管理员后台增加"反馈管理"页面
4. **反馈入口** - 侧边栏底部增加"意见反馈"链接

### 涉及文件
| 文件 | 改动 |
|------|------|
| `backend/app/models/feedback.py` | **新建** - Feedback 模型 |
| `backend/app/schemas/feedback.py` | **新建** - Feedback Schema |
