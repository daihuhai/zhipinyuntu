# 智聘云图 · 软件功能介绍

> 面向求职者 / 企业 HR / 平台管理员的功能使用指南 | v1.2.0

---

## 一、产品概览

**智聘云图**是一款 AI 驱动的智能招聘平台，采用 **三端协同架构**（求职者端 / 企业端 / 管理后台），以 **LLM 文档智能解析 + 六维度匹配引擎** 为核心，覆盖「简历上传 → AI 解析 → 能力图谱 → 精准人岗匹配 → 面试邀请 → 录用反馈」的全流程闭环。

- **技术底座**: Vue 3 + FastAPI + SQLAlchemy + GreatSQL + 灵犀大模型(ARK API) + WebSocket + ECharts
- **核心卖点**: 上传简历/职位描述即自动结构化 → AI 深度分析 → 数据驱动的精准推荐

> 平台所有角色功能均通过浏览器访问，无需安装客户端。登录后根据账号角色自动进入对应工作台。

## 二、注册与登录

| 功能 | 说明 |
|------|------|
| **账号注册** | 支持求职者 / 企业两种角色注册，填写基础信息即可开通 |
| **安全登录** | JWT 双令牌认证（Access Token 120 分钟 + Refresh Token 7 天），自动续期免打扰 |
| **密码找回** | 忘记密码可通过邮箱/手机验证重置 |
| **新用户引导** | 首次登录自动弹出分步引导，快速了解平台核心功能（可跳过） |

## 三、求职者端功能（Seeker Workbench）

面向求职者的完整工作台，覆盖求职全流程。

### 3.1 简历管理

| 功能 | 说明 |
|------|------|
| **AI 简历解析** | 上传 PDF / DOC / DOCX 简历，LLM 自动提取基本信息、教育背景、工作经历、项目经历、技能标签、自我评价 |
| **简历编辑** | 解析结果可手动编辑，支持随时修改完善 |
| **简历列表** | 多份简历管理，查看、编辑、删除 |
| **能力图谱** | 基于技能关联网络的可视化个人画像，直观展示技能掌握情况 |
| **技能雷达图** | 五维能力雷达展示，快速定位技能强弱项 |
| **简历竞争力分析** | 与同岗位候选人对标，展示技能覆盖度、经验年限、学历、匹配得分的百分位，并给出 AI 提升建议 |
| **AI 优化建议** | LLM 多维评估简历质量，给出「原文 → 建议改写」对比，VIP 可一键应用改写 |

### 3.2 职位浏览与投递

| 功能 | 说明 |
|------|------|
| **职位广场** | 浏览全平台在招职位，支持关键词搜索、多条件筛选、按热度/时间排序 |
| **职位详情** | 完整职位信息、技能要求、薪资福利、企业信息展示 |
| **相似职位推荐** | 基于职位类别、城市、薪资、技能相似度智能推荐关联职位 |
| **投递简历** | 一键投递，选择使用哪份简历 |
| **职位收藏** | 心形图标收藏感兴趣职位，收藏列表集中管理 |
| **浏览历史** | 自动记录最近浏览的职位，按时间倒序查看 |
| **职位分享卡片** | 一键生成精美职位分享图（含公司/职位/薪资/二维码），可保存传播 |

### 3.3 投递与跟踪

| 功能 | 说明 |
|------|------|
| **投递记录** | 查看所有投递，按状态筛选（已投递 / 已查看 / 面试邀请 / 不合适 / 已录用） |
| **状态时间轴** | 每条投递展开时间轴，清晰展示各阶段时间节点与操作方 |
| **面试邀请** | 收到企业面试邀请，可在线接受 / 拒绝 |
| **企业评价** | 面试结束后为企业打分（面试体验 / HR 响应 / 描述准确度），匿名展示 |

### 3.4 沟通与账户

| 功能 | 说明 |
|------|------|
| **实时消息** | WebSocket 实时聊天，收到新消息即时推送，未读角标提醒（断线自动重连） |
| **个人仪表盘** | 投递趋势、状态分布、匹配均分统计 |
| **个人设置** | 修改个人资料、密码 |
| **VIP 中心** | 开通会员，解锁 AI 优化建议一键应用等高级能力 |

## 四、企业端功能（Employer Workbench）

面向企业 HR / 招聘人员的招聘管理平台。

### 4.1 职位发布

| 功能 | 说明 |
|------|------|
| **JD 智能解析** | 上传 JD 文件 或 粘贴文本，LLM 自动提取职位名称、薪资、城市、经验/学历要求、技能要求等字段并填充表单 |
| **AI 职位描述生成** | 输入岗位名称 + 级别 + 核心技能，LLM 自动生成职位描述、任职要求、加分项 |
| **表单草稿** | 发布中自动保存草稿，误关闭/超时重新进入可一键恢复 |
| **职位管理** | 已发布职位列表，支持搜索、编辑、下架/重新上架 |

### 4.2 候选人招聘

| 功能 | 说明 |
|------|------|
| **候选人推荐** | AI 基于职位要求推荐匹配候选人，展示匹配分、已匹配/缺失技能 |
| **候选人对比** | 最多勾选 3 人横向对比（匹配分、学历、年限、技能、项目、薪资） |
| **投递管理** | 按职位/状态/姓名筛选，按匹配度/时间排序，支持批量更新状态 |
| **简历在线预览** | 简历抽屉支持「解析视图 / 原文件预览」切换，原文件 iframe 内嵌在线查看 |
| **AI 面试题生成** | 基于候选人简历 + 职位要求，LLM 生成针对性面试题清单（技术深挖/项目追问/行为/开放），可导出 PDF |
| **联系候选人** | 一键发起站内消息沟通 |

### 4.3 沟通与账户

| 功能 | 说明 |
|------|------|
| **实时消息** | WebSocket 实时聊天，未读角标提醒 |
| **企业仪表盘** | 在招职位数、收到简历数、投递趋势、职位投递分布 |
| **企业设置** | 修改企业信息、密码 |
| **Excel 报表导出** | 投递记录一键导出为样式化 Excel 报表（标题行/表头/斑马纹/冻结/自动筛选） |

## 五、管理后台功能（Admin Console）

面向平台管理员的数据监控与系统管理后台。

### 5.1 数据指挥中心

| 功能 | 说明 |
|------|------|
| **核心指标看板** | 用户数、职位数、投递数、注册趋势等核心 KPI 实时展示 |
| **招聘漏斗分析** | 投递 → HR 查看 → 面试邀请 → 录用 全链路转化漏斗，支持近 7/30/90 天筛选 |
| **热门职位 TOP10** | 按投递数排序的职位排行榜 |
| **热门技能词云** | 职位需求技能关键词频率可视化 |
| **用户增长趋势** | 近 30 天求职者 / 企业注册趋势折线图 |
| **匹配分分布** | 全平台匹配得分分布统计分析 |
| **院校 / 城市分布** | 候选人毕业院校、意向城市分布图表 |
| **全屏展示** | 一键隐藏侧边栏/顶栏，9 大方屏图表铺满，适合演示投屏 |
| **实时操作日志** | WebSocket 实时滚动展示平台操作日志流 |

### 5.2 系统管理

| 功能 | 说明 |
|------|------|
| **用户管理** | 管理所有角色用户，增删改查、启停 |
| **简历管理** | 全平台简历数据管理，查看详情、删除 |
| **职位管理** | 全平台职位数据管理，查看详情、删除 |
| **VIP 管理** | 开通/续费/取消用户 VIP，管理免费/付费配额 |
| **营收监控** | 平台营收数据统计与导出 |
| **反馈管理** | 查看用户意见反馈并处理 |
| **操作日志** | 审计日志，记录操作人、操作类型、目标、IP 地址 |

## 八、快速上手

### 求职者三分钟上手
```
注册/登录 → 上传简历(AI 自动解析) → 查看能力图谱 → 职位广场/推荐选择职位 → 投递 → 关注投递时间轴 → 通过消息与 HR 沟通
```

### 企业三分钟上手
```
注册/登录 → 发布职位(AI 解析或生成) → 查看候选人推荐 → 投递管理查看简历(在线预览) → AI 生成面试题 → 发起面试邀请 → 状态流转至录用
```

### 管理员快速巡检
```
登录 → 数据指挥中心(全屏看板) → 用户/简历/职位管理 → 营收与 VIP 管理 → 反馈与日志审计
```
