# 智聘云图 — 功能演示视频录制脚本

> **时长**: 约 6 分 50 秒（控制在 7 分钟内）
> **语速参考**: 中等偏快，约 180-200 字/分钟
> **录制方式**: 屏幕录制 + 旁白配音

---

## 时间轴总览

| 段落 | 内容 | 预计时长 |
|------|------|----------|
| 一、开场 | 产品定位 + 核心价值 | 30s |
| 二、登录注册 | 角色选择 + 注册登录 | 25s |
| 三、求职者端 | 简历上传→AI解析→推荐→图谱→投递→VIP | 120s |
| 四、企业端 | 发布职位→推荐候选人→面试邀请→资质认证 | 90s |
| 五、管理员端 | 数据大屏→用户管理→营收监控→日志审计 | 110s |
| 六、收尾 | 技术亮点总结 + 结束语 | 30s |

## 一、开场（0:00 - 0:30）

### 画面操作
- 打开浏览器，展示产品首页/登录页
- 镜头停留在登录页，展示品牌 Logo 和 "智聘云图" 标题
- 背景展示科技感登录页（玻璃拟态 + 3D 几何元素 + 流体云层效果）

### 台词
> 各位评委老师好，我带来的项目是**智聘云图**——一款基于文档智能解析的人岗匹配平台。
>
> 它的核心思路是：求职者上传简历，系统通过大语言模型自动解析并提取结构化信息，构建能力知识图谱，再通过六维度加权匹配引擎，为求职者和企业实现精准的双向推荐。
>
> 系统采用前后端分离架构，前端 Vue 3 + TypeScript + Element Plus，后端 FastAPI + SQLAlchemy，AI 层接入字节跳动豆包大模型。共覆盖**求职者、企业、管理员**三个角色，接下来我按角色逐一演示。

---

## 二、登录与注册（0:30 - 0:55）

### 画面操作
1. 点击"注册"按钮，展示角色选择（求职者/企业二选一）
2. 快速输入用户名、密码、邮箱，完成注册
3. 切换到登录页，输入账号密码完成登录
4. 登录后自动跳转到对应工作台

### 台词
> 首先看登录注册模块。系统采用三角色 RBAC 权限模型，注册时需要选择身份——求职者还是企业。
>
> 密码采用 bcrypt 加密存储，登录使用 JWT 双 Token 机制，Access Token 有效期 2 小时，Refresh Token 7 天，并且对登录和注册接口做了速率限制，防止暴力破解。
>
> 登录后，系统会根据角色自动路由到对应的工作台，三个角色之间的数据完全隔离，即使知道对方的 URL 也无法越权访问。

## 三、求职者端（0:55 - 2:55）

### 3.1 仪表盘 + 简历上传（0:55 - 1:35）

#### 画面操作
1. 登录后进入求职者仪表盘，展示简历概览卡、投递统计、推荐职位
2. 点击"上传简历"，选择一份 PDF 简历文件
3. 上传过程中展示进度条，上传完成后自动触发 AI 解析
4. 解析完成后展示解析结果：姓名、学历、技能清单等结构化信息
5. 紧接着展示 AI 智能分析结果：完整度评分 + 改进建议列表

#### 台词
> 登录后首先看到求职者仪表盘，这里汇总了简历状态、投递统计和系统推荐的热门职位。
>
> 现在演示核心功能——简历上传与智能解析。我上传一份 PDF 简历，系统首先用 pdfplumber 提取文本，然后调用豆包大模型进行结构化解析。大家可以看到，LLM 自动提取出了姓名、学历、学校、技能清单、工作经历、项目经历、期望薪资等全部字段。
>
> 解析完成后，系统还会自动触发 AI 智能分析，从 8 个维度评估简历完整度，并给出分优先级的改进建议。求职者可以一键采纳建议，技能类建议会自动添加到技能清单，文本类建议会预填到编辑表单。

### 3.2 简历管理 + 能力图谱（1:35 - 2:00）

#### 画面操作
1. 进入简历列表，展示已上传的简历
2. 点击某份简历的"能力图谱"按钮
3. 展示知识图谱页面：中心是求职者节点，中层是技能分类，外层是具体技能
4. 选择一个目标岗位，展示匹配效果：已匹配技能绿色连线，缺失技能红色标记
5. 右侧雷达图展示技能分布，底部环形进度条展示匹配度

#### 台词
> 简历列表可以看到所有已上传的简历，支持在线编辑、查看详情和删除。
>
> 重点看一下能力关系图谱。这是知识图谱模块的核心可视化。图谱采用三层结构——中心是求职者，中层是技能分类节点，外层是具体技能。当我选择一个目标岗位后，系统会高亮已匹配的技能，用绿色连线标识，缺失的技能用红色节点标记。右侧还有技能分布雷达图和匹配度环形进度条，让求职者一目了然地看到自己和目标岗位的差距。

### 3.3 职位广场 + AI 智能推荐（2:00 - 2:35）

#### 画面操作
1. 进入职位广场，展示职位卡片列表（含筛选搜索）
2. 点击某个职位进入详情页
3. 职位详情页展示：基本信息 + 岗位要求图谱（必须/优先技能）
4. 返回，进入"智能推荐"页面
5. 展示推荐结果：综合匹配度百分比 + 六维度评分明细 + LLM 生成的匹配理由
6. 点击"投递"按钮完成投递

#### 台词
> 职位广场支持按关键词、城市、学历、薪资区间筛选。进入职位详情，可以看到完整的岗位信息和技能要求图谱——红色节点代表必须技能，黄色节点代表优先技能，这是用 ECharts 力导向图实现的。
>
> 再来看智能推荐。这是系统的核心引擎——采用**召回 → 粗排 → 精排**三阶段流程。粗排阶段用六维度加权算法快速筛选，六个维度分别是技能 40%、经验 20%、学历 15%、城市 10%、薪资 10%、项目 5%。精排阶段由 LLM 综合评估，生成自然语言的匹配理由。
>
> 这里还做了两个关键性能优化：一是批量精排，把 4 个候选人合并为 1 次 LLM 调用，耗时从 28 秒降到 3 秒；二是匹配缓存，2 小时内的重复查询直接复用历史结果，耗时仅 0.09 秒。找到合适的职位后，一键投递即可。

### 3.4 投递记录 + 面试 + 消息中心 + VIP（2:35 - 2:55）

#### 画面操作
1. 进入投递记录，展示投递列表和状态
2. 快速展示收藏列表
3. 进入消息中心，展示未读消息徽章和消息列表
4. 进入个人设置，展示 VIP 会员卡
5. 快速切到 VIP 中心，展示套餐和支付页面

#### 台词
> 投递记录页面追踪每一次投递的状态流转——从待处理到已查看、面试邀请、录用，求职者也可以在待处理阶段主动撤回。
>
> 消息中心通过 WebSocket 实时推送，面试邀请、投递反馈都会即时送达，sidebar 上有未读消息数量的红点徽章。
>
> 最后看一下 VIP 体系。系统采用双轨制计费——VIP 会员订阅不限次，加上单次付费按需购买。免费用户每天有 2 次 AI 匹配配额。支付流程模拟了微信和支付宝的扫码支付，订单确认后配额立即生效。

## 四、企业端（2:55 - 4:25）

### 4.1 企业仪表盘 + 发布职位（2:55 - 3:25）

#### 画面操作
1. 切换到企业端登录（或直接展示企业工作台）
2. 展示企业仪表盘：职位统计、投递统计、候选人推荐
3. 点击"发布职位"，填写职位信息表单
4. 动态添加技能要求（必须/优先），填写职位描述
5. 发布成功

#### 台词
> 切换到企业端。企业仪表盘展示已发布职位数、收到的投递数和系统推荐的候选人。现在演示发布一个职位——我填写职位标题、薪资范围、学历经验要求，然后动态添加技能要求，每个技能可以标记为"必须"或"优先"。职位描述支持 Markdown 格式。发布后可以在职位列表中进行上架、下架、编辑等管理操作。

### 4.2 候选人推荐 + 面试邀请（3:25 - 4:00）

#### 画面操作
1. 进入候选人推荐页面
2. 展示 AI 推荐的候选人列表：综合匹配度、六维度评分、匹配理由
3. 点击某个候选人查看简历详情
4. 对合适的候选人，点击"发送面试邀请"
5. 填写面试时间、地点、形式、联系人等信息
6. 发送成功后，展示投递状态自动更新为"面试邀请"

#### 台词
> 候选人推荐是企业的核心功能。系统同样使用六维度匹配引擎，从技能、经验、学历、城市、薪资、项目六个维度评估候选人与岗位的匹配度。LLM 还会生成一句话的推荐理由，帮助 HR 快速判断。
>
> 对合适的候选人，可以直接发送面试邀请。填写面试时间、地点、面试形式和联系人信息后，系统会通过 WebSocket 实时推送给求职者，同时自动更新投递状态为"面试邀请"。求职者可以在自己的消息中心收到通知，选择接受或拒绝。

### 4.3 投递管理 + 资质认证 + VIP（4:00 - 4:25）

#### 画面操作
1. 进入投递管理，展示收到的所有投递
2. 演示状态流转：标记已查看、不合适、录用
3. 进入企业设置，展示营业执照认证入口
4. 快速展示上传营业执照页面
5. 展示 VIP 会员卡和 VIP 中心

#### 台词
> 投递管理页面可以看到所有收到的求职申请，支持批量处理。HR 可以标记已查看、发送面试邀请、标记不合适或录用的状态流转。
>
> 企业还可以提交营业执照进行资质认证，管理员审核通过后会展示"已认证"标识，提升企业可信度。同样，企业端也有 VIP 会员体系，享受不限次 AI 推荐和更多配额。

## 附录：录制注意事项

### 画面准备
1. **提前登录三个账号**，准备好浏览器标签页，避免录制时等待
2. **准备一份测试 PDF 简历**，确保能正常解析
3. **管理员端提前准备好数据**，确保图表有数据可展示
4. **关闭无关浏览器标签页和通知**，保持画面干净
5. **推荐分辨率**: 1920×1080，缩放 100%

### 录制技巧
1. 鼠标移动平稳，不要过快晃动
2. 关键操作点停留 1-2 秒，给评委看清的时间
3. 表单填写可以提前准备好内容，录制时快速粘贴
4. 切换页面时稍作停顿，旁白跟上节奏
5. 大屏页面可以适当滚动，展示完整内容

### 备用方案
- 如果某个 AI 接口响应慢，可以提前录制好该段，后期剪辑进去
- 如果网络不稳定，建议使用本地录屏 + 后期配音的方式
- 可以分段落录制，后期拼接，每段之间留 2 秒黑场过渡

### 时间控制
- 如果超时，优先压缩管理员端图表展示（每个图表 2-3 秒快速滑过）
- 如果时间充裕，可以在智能推荐部分多展示匹配理由细节
- 建议正式录制前先完整走一遍流程计时
